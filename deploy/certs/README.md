# 会社の証明書（必要なときだけ）

会社のプロキシが HTTPS の通信を検査している（会社の証明書で署名し直している）と、イメージを作るときの
apt / pip / npm が「証明書を確かめられない」というエラーで止まります。そのときは会社のルート証明書を
**PEM 形式・拡張子 `.crt`** でサーバーの `/srv/ops/certs/` に置いてください。
`deploy/install.sh` が版を入れるたびにこのフォルダーへ写し、ビルドのときに信頼させます。

- `.crt` が 1 つも無ければ何も変わりません（検査のないプロキシや、直接インターネットに出られる場合）。
- このフォルダーの `.crt` は git に入れません（`.gitignore`）。証明書はサーバーの `/srv/ops/certs/` に 1 回置くだけです。
- `docker pull` で同じエラーが出るときは、サーバーの OS にも同じ証明書を入れます（[README.md](../README.md) の 0.）。
