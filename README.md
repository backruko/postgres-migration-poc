# postgres-migration-poc
本プロジェクトは、従来のアナログ作業および老朽化したレガシーシステムに依存していた信販決済業務を、最新の API 駆動型マイクロサービス（FastAPI）とモダンフロントエンド（React）へ完全脱却（DX 推進）させるPoCプロジェクトです。複雑な金融カレンダーおよび二重オフセット計算の完全自動化・ノータッチ化を実現します。

### ■ 本システムの核心技術：二重ステートマシンとSOPバージョニング

1. **二重ステートマシン（Double State Machine）による高粒度プロセス管理**
   * **ワークフロー階層:** 案件全体の進捗ステータス（申請・審査・承認・完了）を徹底管理。
   * **SOPタスク階層:** 各工程における具体作業手順（SOPステップ）ごとの実行・完了・異常状態を精密に制御。
   * **効果:** 業務のブラックボックス化を完全に排除し、ボトルネックのリアルタイム検知およびSOP順守率100%を達成。

2. **監査適合性を担保する「SOPバージョンコントロール」**
   * 金融法改正や決済ルール変更に伴うSOPアップデートに対応し、**SOP仕様の完全バージョン管理**を実装。
   * 過去の案件は「発生当時のSOPバージョン」に基づき完全追跡（Traceability）可能とし、将来のJ-SOX・内部監査における「制度変更時の遡及不可可能性」リスクを根本解決。

## 4. 今後のロードマップ（Roadmap & Future Scope）

### 【Phase 1】基幹ロジックの検証＆モダン全栈アーキテクチャのPoC確立（※完了）
* **金融カレンダー・二重オフセット計算エンジンの開発:** 
  祝日順延・二重補正等の複雑な決済日判定ルールを完全アルゴリズム化。
* **次世代Web基盤（FastAPI + React）の設計・実装:** 
  レスポンス速度の向上およびペーパーレス化（SLA順守）を見据えたSPA/API分離型アーキテクチャの構築。
* **ローカル環境におけるPoC（概念実証）の完了:** 
  シミュレーションデータを用いた網羅的なロジック検証およびUI/UXの動作確認を完了。

### 【Phase 2】社内既存インフラ・ミドルウェアとの連携強化（※予定）
* **エンタープライズ・ミドルウェア連携（HULFT / JobCenter）:** 
  既存のバッチジョブ（JobCenter）および安全なデータ連携基盤（HULFT）とのAPIブリッジ接続。
* **ステージング環境での本番相当テスト（Staging Verification）:** 
  アクセス権限・IPアドレス等のネットワーク要件定義、および負荷テスト（Benchmarking）の実施。
* **監査ログ・セキュリティ基盤の強化:** 
  金融系システムのコンプライアンス要件を満たす全操作ログの自動追跡（Audit Trail）機能の実装。

### 【Phase 3】信販系ソリューションとしての横展開・サービス化（※将来展望）
* **ノンバンク・信販事業者向けパッケージ（DXソリューション）としての展開:** 
  他社向け基幹・周辺システムの刷新（Legacy Modernization）案件へのコンポーネント転用。
* **マイクロサービス化・SaaS基盤への拡張:** 
  クラウド環境（AWS/Azure）へのコンテナ（Docker）デプロイによるスケーラビリティの確保。

※ 本資料は PoC（概念実証）段階の環境に基づく推計値であり、本番運用にあたってはインフラ環境（IP・ネットワーク等）の整備および本番データの接続検証が別途必要となります。
